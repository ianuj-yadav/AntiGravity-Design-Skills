## 📖 Overview

**AntiGravity Design Skills** provides a suite of specialized capabilities intended to enhance the visual aesthetics and user experience of web and mobile applications generated by AI agents. It moves beyond simple minimum viable products, focusing on premium design systems, beautiful typography, micro-interactions, and modern layout conventions.

## 🚀 How to Install in AntiGravity

To use these skills in your AntiGravity IDE agentic environment, you can install them as global customizations or workspace customizations.

### Option 1: Workspace Installation (Recommended for specific projects)
1. Open your project folder in your terminal or git client.
2. Clone this repository directly into your project as the `.agents` folder:
   ```bash
   git clone https://github.com/ianuj-yadav/AntiGravity-Design-Skills.git .agents
   ```
3. Restart or reload your AntiGravity agent conversation. The skills will be automatically discovered and loaded!

### Option 2: Global Installation (Available across all projects)
1. Navigate to your global AntiGravity config directory (e.g., `C:\Users\YourUser\.gemini\config`).
2. Clone or copy the `skills` folders from this repository into the `skills` directory of your global config.
3. Your agent will now have access to these design skills globally.

> **Note:** Sensitive configuration files (like `mcp.json`) are ignored in this repository. If any of the skills require API keys or specific platform integrations, please configure your local `mcp.json` accordingly.
