## 📖 Overview

**AntiGravity Design Skills** provides a suite of specialized capabilities intended to enhance the visual aesthetics and user experience of web and mobile applications. It moves beyond minimal viable products, focusing on premium design systems, beautiful typography, micro-interactions, and modern layouts.

## 🚀 Features

- **Advanced UI Styling (`advanced-ui-styling`)**: Apply cutting-edge design trends like Glassmorphism, Neoclassical, Aurora, Neo Brutalism, Vaporwave, and more.
- **UI/UX Pro Max (`ui-ux-pro-max`)**: A comprehensive design intelligence system providing 50+ styles, 21 color palettes, 50 font pairings, and support for 9+ tech stacks.
- **Ready-to-use Datasets**: Includes extensive resources for typography, color theory, component states, and accessibility guidelines.

## 🛠️ Usage

To utilize these skills in your own agentic environments or IDE workflows:

1. Clone this repository into your local `.agents` or global config directory.
2. Ensure the `mcp.json` context configurations are properly set up for your specific agent platform (Note: sensitive keys are purposefully omitted from this public repository).
3. Call the specific skill by name (e.g., `advanced-ui-styling`) in your prompts to apply its design logic to your codebase.
