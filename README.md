## 🎨 Dual-Flavor UI Kits & Design Systems

This repository contains production-ready implementations in **two flavors**:

### 1. Pure HTML5 + CSS3 + Vanilla JS Edition (`/html-css-js-hub`)
Zero build step required. Drop into any static website, Webflow project, or browser application:
- **Interactive Hub**: `html-css-js-hub/index.html`
- **Universal Tokens**: `html-css-js-hub/css/design-tokens.css`
- **Vanilla JS Engine**: `html-css-js-hub/js/main.js` (GSAP, Lenis, Three.js 3D Floating Particles, Stitch MCP Studio)
