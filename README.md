## 📖 Overview

**AntiGravity Design Skills** provides a suite of specialized capabilities intended to enhance the visual aesthetics and user experience of web and mobile applications generated by AI agents. It moves beyond simple minimum viable products, focusing on premium design systems, beautiful typography, micro-interactions, and modern layout conventions.

## 🧰 The Design Arsenal (Available Skills)

This repository is packed with powerful, ready-to-use skills tailored for design excellence. Each skill acts as a specialized agentic brain to transform ordinary applications into stunning visual experiences.

### 🌟 UI/UX Pro Max (`ui-ux-pro-max`)
The ultimate crown jewel of this repository. **UI/UX Pro Max** is a comprehensive, encyclopedic design intelligence system. It acts as an elite design director for web and mobile applications. 
* **Unmatched Scale**: Comes loaded with **50+ curated design styles**, **21+ dynamic color palettes**, and **50+ flawless font pairings**. 
* **Data Visualization**: Includes 20 specialized chart aesthetics for gorgeous data storytelling.
* **Broad Compatibility**: Fully supports over 9 different technology stacks (including React, Next.js, Vue, Svelte, and Flutter), ensuring your agent writes the exact right CSS/UI code for your framework.
* **Why it's incredible**: It takes away the guesswork. Whether you need a sleek dark mode dashboard or a vibrant landing page, this skill feeds the agent precise, beautiful constraints.

### 🎨 Advanced UI Styling (`advanced-ui-styling`)
Why settle for a basic flat UI when you can build modern art? This skill specifically targets the absolute cutting-edge of UI design trends.
* **Next-Gen Aesthetics**: Automatically guides the agent to implement **Glassmorphism** (beautiful frosted glass overlays), **Neoclassical** typography grids, mesmerizing **Aurora** background gradients, **Ethereal** lighting effects, **Vaporwave** retro aesthetics, and bold **Neo-Brutalism**.
* **Why it's incredible**: It forces the AI to break out of "default Bootstrap" thinking and pushes the envelope on what web design can look like, producing results that will instantly "wow" users.

### ✨ Awesome Design Skills (`awesome-design-skills`)
A curated library of best practices, UI integrations, and micro-interaction logic.
* **Component Elevation**: Takes standard base components (like buttons, modals, and navbars) and injects them with smooth transitions, perfect padding ratios, and delightful hover states.
* **Why it's incredible**: It focuses on the "feel" of the application, ensuring that the user experience is as smooth and tactile as the visual design.

### 🧩 Stitch Kit (`stitch-kit`)
The architectural backbone for component generation.
* **Robust Utilities**: Provides the underlying logic and utilities required for dynamic component generation and "stitching" together complex UI fragments seamlessly.
* **Why it's incredible**: It ensures that while the other skills make things beautiful, the code generated remains modular, clean, and highly scalable.

### 🧵 Stitch UI Skill (`stitch-ui-skill`)
Brings the power of Google Stitch directly into your IDE.
* **MCP Integration**: Facilitates complete UI generation workflows utilizing the Google Stitch Remote MCP API.
* **Why it's incredible**: It acts as a bridge to enterprise-level design generation pipelines, allowing for seamless export of production-ready, beautiful code tailored to your exact prompt.

## 🚀 How to Install in AntiGravity

To use these skills in your AntiGravity IDE agentic environment, you can install them as global customizations or workspace customizations.

### Option 1: Workspace Installation (Recommended for specific projects)
1. Open your project folder in your terminal or git client.
2. Clone this repository directly into your project as the `.agents` folder:
   ```bash
   git clone https://github.com/ianuj-yadav/AntiGravity-Design-Skills.git .agents
   ```
3. Restart or reload your AntiGravity agent conversation. The skills will be automatically discovered and loaded!

### Option 2: Global Installation (Available across all projects)
1. Navigate to your global AntiGravity config directory (e.g., `C:\Users\YourUser\.gemini\config`).
2. Clone or copy the `skills` folders from this repository into the `skills` directory of your global config.
3. Your agent will now have access to these design skills globally.

> **Note:** Sensitive configuration files (like `mcp.json`) are ignored in this repository. If any of the skills require API keys or specific platform integrations, please configure your local `mcp.json` accordingly.
