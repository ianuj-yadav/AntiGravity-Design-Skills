# Universal UI/UX Design System Hub (`universal-ui-kits`)

This skill equips the agent with instant, production-grade templates and architecture patterns to implement design systems and SaaS components in **two flavors**:
1. **React / Next.js 15 App Router + Tailwind CSS**
2. **Pure HTML5 + Vanilla CSS3 + JavaScript (Zero build step)**

## Supported UI Kits & Layouts

1. **Dark Bento UI Kit**: Glassmorphic bento grids, responsive multi-column cards, interactive hover telemetry.
2. **Blank 2.7**: Clean and minimal design system focusing on typography, density, and spacing hierarchy (`--space-2xs` to `--space-3xl`).
3. **MagicDraft & FinStack**: AI SaaS dashboard kits and financial metrics KPI widgets.
4. **ElementX & Enterprise UI Kit**: High-density business data tables, search/filter bars, SLA tags.
5. **Zeus & ChainStock**: Bold UI kits and real-world asset (RWA) tokenized landing pages.
6. **Integrated Component Libraries**:
   - `8bitcn`: Retro pixel arcade borders and gamified badges.
   - `Magic UI / Aceternity UI / Kokonut UI / React Bits`: 3D interactive hero banners and animations.
7. **Animation Stack**:
   - `Lenis`: Smooth momentum scrolling.
   - `GSAP + ScrollTrigger`: High-performance timeline animations.
   - `Three.js`: 3D floating nodes and WebGL canvases.
8. **Google Stitch MCP Studio**:
   - Structured prompt synthesis `[Context] [Layout] [Theme Tokens] [Components]`.
   - CSS custom property design token export.

## Usage Guide

- For **React/Next.js** projects, reference `react-nextjs-hub/` patterns or `ultimate-ui-hub`.
- For **HTML/CSS/JS** static sites or Webflow embeds, reference `html-css-js-hub/index.html` and `html-css-js-hub/css/design-tokens.css`.
