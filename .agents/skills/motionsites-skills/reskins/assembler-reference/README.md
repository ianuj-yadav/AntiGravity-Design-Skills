# Site assembler reference (#5)

The Philosophy-fix generalized: one shared brand **Shell** (glass-pill nav + brand `:root`) wraps N
page-bodies via react-router. Each body is a reskinned template mechanic; coherence comes from the
shared shell + brand tokens, not from forcing one layout.

- `Shell.tsx` — fixed glass-pill nav, brand-tokened, with `<Outlet/>` for the body
- `main.tsx` — router: `Shell` layout route → `/` (orbit hero body) + `/manifesto` (second body)
- `Manifesto.tsx` — a second stacked body sharing the same skin

Demonstrated live in `shamoni-landing` (Thoughtseed-reskinned). Production adds inter-page
transitions + per-template bodies generated by reskin.mjs / reskin-theme.mjs.
