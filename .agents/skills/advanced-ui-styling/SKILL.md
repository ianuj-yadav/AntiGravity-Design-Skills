# Advanced UI Styling Guidelines

When instructed to improve UI design or apply advanced aesthetics, incorporate the following styles based on the project's brand and context. The goal is to provide a "WOW" factor and avoid basic minimal viable products.

## Core Styles to Utilize:

1. **Glassmorphism**: 
   - Use translucent frosted glass effects, subtle background blur (`backdrop-filter: blur()`), light borders, and soft drop shadows.
   - Creates depth and a modern, premium feel for cards and overlays.

2. **Neoclassical**: 
   - Integrate elegant, timeless design elements combined with modern layouts. 
   - Use sophisticated typography (e.g., serif headings with sans-serif body), structured grids, and refined, muted color palettes.

3. **Aurora (Aurora Borealis/Gradient effects)**: 
   - Utilize fluid, organic, and blurred multi-color mesh gradients in the background.
   - Creates a dreamy, dynamic, and modern look.

4. **Ethereal**: 
   - Focus on light, airy, and delicate visuals. 
   - Use soft pastel colors, ample white space, fine lines, and subtle glow effects to make the UI feel weightless.

5. **Anthropomorphic**: 
   - Add human-like or organic characteristics to interface elements. 
   - Use soft, relatable shapes, micro-interactions that feel "alive" or responsive, and engaging, conversational copy.

6. **Pixel Art**: 
   - For specific retro, nostalgic, or gamified contexts.
   - Utilize pixelated graphics, blocky typography, and classic 8-bit or 16-bit color palettes.

7. **Conceptual Sketch**: 
   - Incorporate hand-drawn or sketch-like elements, wireframe-style aesthetics.
   - Use illustrative components that feel raw, creative, and artistic.

8. **Vaporwave & Modular Typography**: 
   - Combine retro 80s/90s aesthetics (neon colors, grid patterns, synthwave vibes) with structured, modular typographic layouts.
   - Text blocks should act as visual building blocks in the layout.

9. **Neo Brutalism**: 
   - Embrace bold, raw, and unapologetic design. 
   - Use stark contrasts, thick bold borders, stark shadows (without blur), vivid/clashing colors, and unrefined structural elements that stand out strongly against traditional clean UI.

## Implementation Principles
- Always prioritize visual excellence.
- Use dynamic interactions (hover states, micro-animations, transitions).
- Select curated modern typography over browser defaults.
- Avoid generic colors; use carefully curated HSL palettes.
